# 🧰 Mini Toolbox - Python 实用工具箱

6 个实用小工具合集，覆盖日常开发高频场景。

## 🛠️ 工具列表

| 工具 | 功能 | 命令 |
|------|------|------|
| text_replace | 批量文本替换 | `python tools/text_replace.py` |
| json_format | JSON 格式化 | `python tools/json_format.py` |
| batch_rename | 文件批量重命名 | `python tools/batch_rename.py` |
| text_diff | 文本对比 | `python tools/text_diff.py` |
| regex_test | 正则表达式测试 | `python tools/regex_test.py` |
| quick_cmd | 快捷命令集 | `python tools/quick_cmd.py` |

## 🚀 快速开始

```bash
# 无外部依赖，纯标准库
python tools/text_replace.py --help
python tools/json_format.py input.json
python tools/batch_rename.py --folder ./photos --pattern "IMG_{n}"
```

## 📦 技术栈

- Python 3.10+（纯标准库，无外部依赖）
